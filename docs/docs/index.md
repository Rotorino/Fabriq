# Fabriq

Fabriq — это современная система имитационного моделирования производственных линий. Проект включает в себя дискретно-событийный движок, расчет аналитических метрик, генерацию отчетов и интерактивный веб-интерфейс.

## Быстрый старт
Для быстрого погружения в работу с системой используйте следующие руководства:

- **[Руководство пользователя](../USER_GUIDE.md)** — установка, запуск CLI и работа с Streamlit UI.
- **[Руководство разработчика](../DEVELOPER_GUIDE.md)** — архитектура системы, Event Loop и расширение функционала.

## Основные возможности
- **15 готовых сценариев**: От базовых моделей до стресс-тестов ("Массовая партия", "Узкое место", "Хрупкие станки").
- **Интерактивный UI**: Встроенный редактор JSON, визуализация производственной линии и история запусков.
- **Глубокая аналитика**: Автоматический расчет КПД оборудования, очередей и пропускной способности.
- **Гибкость**: Поддержка различных режимов генерации партий (фиксированный интервал, случайный и др.).

## Запуск приложения

### CLI
```bash
python -m app.main --config configs/base_scenario.json
```

### Web UI
```bash
streamlit run app/ui.py
```

## Состав системы

```text
app/            Точки входа (CLI и UI)
domain/         Общие сущности (Станок, Партия, Этап)
scenario/       Загрузка, валидация и сборка сценариев
engine/         Дискретно-событийное ядро (Event Loop)
analytics/      Расчет бизнес-метрик
reporting/      Экспорт отчетов (JSON, CSV, TXT)
visualization/  Построение графиков и схем
configs/        Библиотека сценариев (15 файлов)
tests/          Unit- и интеграционные тесты
```
