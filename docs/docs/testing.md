# Проверка ядра

Unit-тесты ядра находятся в `tests/test_engine.py`.

Запуск:

```bash
python -m unittest discover -s tests -q
```

Дополнительная проверка синтаксиса:

```bash
python -m compileall app domain scenario engine analytics reporting visualization tests
```

Проверка полного запуска:

```bash
python -m app.main --config configs/base_scenario.json
python -m app.main --config configs/high_load.json
python -m app.main --config configs/frequent_breakdowns.json
```

## Что покрывают тесты

Текущие тесты проверяют:

- порядок событий в `EventQueue`;
- стабильность сортировки событий с одинаковым временем;
- ошибку при извлечении события из пустой очереди;
- прохождение партии через несколько этапов;
- ожидание партии при занятом станке;
- корректную работу ограниченной очереди при зарезервированном старте обработки;
- отправку партии в буфер при заполненной очереди;
- выбраковку партии при заполненной очереди и заполненном или отключенном буфере;
- параллельный старт разных партий на разных станках;
- поломку станка, повторную постановку партии в очередь после ремонта и завершение прерванной обработки;
- выбраковку партии;
- обработку события завершения ровно на `simulation_duration`.
- повторный запуск одного и того же объекта сценария без накопления состояния
  во входных партиях, очередях и станках.

## Критерии готовности ядра

Ядро считается готовым к интеграции, если выполняются условия:

- события обрабатываются в правильном порядке;
- партия проходит через этапы корректно;
- при отсутствии свободного станка партия остается в очереди;
- при заполненной очереди партия отправляется в буфер или выбраковывается, если буфер недоступен;
- после завершения обработки партия переходит дальше по маршруту;
- поломка станка влияет на обработку и планирует ремонт;
- после ремонта прерванная партия возвращается в очередь и дорабатывает оставшееся время;
- симуляция завершается без зависаний;
- формируется журнал событий с временем, типом события, партией, этапом, станком и результатом.
- повторный запуск сценария возвращает результат по копиям входной модели и не
  портит исходные объекты.
